Awdur
=====

**awdur - (n.) author**

Experiments in blending code and documentation, inspired by literate programming,  powered by docutils.

I don't really know how good of an idea this is yet, or if it will be worth pursuing long-term.
But if you are interested, below are some examples of what is currently possible with the project.
